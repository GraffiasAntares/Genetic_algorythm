# Генетический алгоритм на C++

Учебная реализация генетического алгоритма на C++ с нуля, без сторонних библиотек.

## Идея

Генетический алгоритм ищет решение задачи, имитируя естественный отбор:

1. создаётся случайная популяция особей (хромосом);
2. каждая особь оценивается функцией приспособленности (fitness);
3. из популяции выбираются родители (селекция);
4. родители скрещиваются и дают потомков, возможна мутация;
5. шаги 2–4 повторяются, пока не будет найдено хорошее решение.

## Как устроен код

- **Хромосома** — массив из `chromo_length` генов (0 или 1), по умолчанию 10.
- **Популяция** — `population_length` хромосом, по умолчанию 10.
- **Приспособленность** — сумма генов хромосомы (задача «OneMax»: чем больше единиц, тем лучше).
- **Скрещивание** — одноточечный кроссинговер: первая половина хромосомы от первого родителя, вторая от второго.
- **Селекция** — задуманы три варианта: пропорциональная, турнирная и ранговая (выбирается параметром `selection_type`).
